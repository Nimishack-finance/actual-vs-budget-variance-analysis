# ACTUAL-VS-BUDGET-VARIANCE-ANALYSIS
Excel-based financial analysis project comparing actual and budgeted revenue and expenditure, with variance analysis and an interactive dashboard.
Excel-based financial analysis project comparing actual and budgeted revenue and expenditure, with variance analysis and an interactive dashboard. Project Overview: This is a sample healthcare financial analysis project based on 2,500+ financial records. The project focuses on comparing budgeted and actual revenue and expenses across different departments, business units, categories, and regions to understand financial performance and resource utilization.

Objective:

To compare budgeted vs actual revenue and expenses.
To identify significant favorable and unfavorable variances across different areas.
To evaluate the efficient utilization of financial resources.
To identify areas where resources may be underutilized, overutilized, or inefficiently utilized.
To support management in identifying areas that require further review and financial attention.
Tools Used:

Microsoft Excel
Excel Tables
Formulas (SUMIF, SUMIFS, IF, etc.)
Conditional formatting
Pivot table
Pivot charts
Slicers
Dashboard
Process / Methodology

Raw Data → Data Cleaning → Calculations → Financial Analysis → Pivot table → KPI Calculation → Dashboard The workbook includes separate sheets for raw data, cleaned data, financial analysis, Pivot table, and the final dashboard.

KPIs / Metrics

Total Budgeted Revenue

Total Actual Revenue

Total Budgeted Expense

Total Actual Expense

Revenue Variance

Expense Variance

Favorable / Unfavorable Variance

Analysis / Key Insights: The analysis compares budgeted vs actual revenue and expenses across departments, categories, and business units. Overall, revenue performance is slightly below budget in most categories and business units, indicating areas where revenue generation requires further attention. Expense performance is mixed, with some areas operating below budget (favorable) while others exceeded the planned budget (unfavorable). At the department level, both favorable and unfavorable variances were observed, showing differences in financial performance and resource utilization across departments. The analysis also includes monthly performance tracking to observe changes in revenue and expenses over time. Favorable and unfavorable variances were classified using the defined financial logic: higher-than-budget revenue is favorable, while lower-than-budget expense is favorable. The analysis helps highlight areas requiring management attention and further review of resource utilization. Management Implication The identified unfavorable variances can be used as a starting point for further investigation and resource-efficiency review. A more detailed drill-down into the underlying categories, services, or cost components would be required to identify the specific drivers behind a particular unfavorable variance and determine the appropriate corrective action.

 Dashboard: 

The project includes an interactive Excel dashboard developed using PivotTables, PivotCharts, and Slicers. The dashboard allows users to filter and view financial data by different dimensions such as department, business unit, category, region, and time period. It provides a quick view of budgeted and actual amounts, allowing users to identify how financial values change across different areas and periods. The connected PivotTables, Pivot charts, and Slicers make the dashboard interactive and allow users to explore the data dynamically.
